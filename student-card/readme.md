# Student Card Management System

## About Project

Student Card Management System is a web-based application developed using React.js.

This project helps manage student information through a simple and responsive dashboard.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- NPM
- Git
- GitHub

## Features

- Student Dashboard
- Add New Student
- View Student Details
- Delete Student
- Search Students
- Student Profile Cards
- Total Student Count
- Active Student Count
- Department Count
- Responsive Design
- Reusable Components

## Installation

### Step 1: Clone Repository

git clone YOUR_GITHUB_REPOSITORY_URL

### Step 2: Navigate to Project

cd student-card

### Step 3: Install Dependencies

npm install

### Step 4: Run Project

npm run dev

## Reusable Components

1. StudentCard.jsx
   Displays individual student details.

2. StudentForm.jsx
   Adds new student information.

3. StudentList.jsx
   Displays multiple student cards.
